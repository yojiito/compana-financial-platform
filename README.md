# カンパス (Compass) - 企業羅針盤・上場企業財務分析プラットフォーム

企業の航路を照らす羅針盤「カンパス（Compass）」。
有価証券報告書（EDINET）の10年財務諸表、TradingView株価チャート、大株主名簿、5%大量保有報告、増資・資金調達履歴を直感的に可視化・分析できるフルスタックWebプラットフォームです。

---

## 🌟 主要機能

1. 📈 **TradingViewローソク足株価チャート**
   - `@tradingview/lightweight-charts` を採用した高速・軽量なチャート。
   - 日足ローソク足（上昇: 赤 / 下落: 青）、25日・75日移動平均線（SMA）、出来高バー。
   - 決算発表イベントのマーカー表示。

2. 📊 **財務3表 10年推移ビジュアライザー**
   - **損益計算書 (PL)**: 売上高・営業利益・純利益の推移バー ＋ 営業利益率の折れ線。
   - **貸借対照表 (BS)**: 総資産 vs 純資産（自己資本）のバランス、自己資本比率推移。
   - **キャッシュフロー (CF)**: 営業活動CF（本業の稼ぎ）、投資活動CF、フリーCF（余力）。
   - **詳細財務テーブル**: EPS、BPS、1株配当金などの年次推移表。

3. 👥 **大株主名簿 & 5%ルール大量保有報告追跡**
   - 有価証券報告書ベースの**上位10名の大株主名簿**（保有株数、持株比率、前期比増減）。
   - 機関投資家・ファンド・アクティビストによる**5%ルール大量保有報告書 / 変更報告書**の提出履歴・保有目的。

4. 💰 **資金調達 & 負債構成診断**
   - 公募増資、第三者割当増資、新株予約権（ワラント）、普通社債、転換社債（CB）等の発行タイムライン。
   - 潜在希薄化率、割当先、資金使途。
   - 有利子負債合計（短期/長期借入・社債）とD/Eレシオ診断。

5. 🔍 **マルチ条件 銘柄スクリーナー**
   - ROE、PER、PBR、配当利回り、自己資本比率、業種をインタラクティブなスライダーで絞り込み。
   - 「羅針盤厳選」「割安バリュー」「高配当」などのワンクリックプリセット機能。

6. 📑 **EDINET / TDnet 開示書類タイムライン**
   - 有価証券報告書、四半期報告書、決算短信、適時開示資料への直接リンク。
